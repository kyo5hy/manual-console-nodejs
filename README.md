## 📖 Sobre o Projeto

Olá! Bem-vindo ao nosso projeto! 😊

Nós somos programadores iniciantes e criamos este guia para aprender e compartilhar o que descobrimos sobre o módulo `console` no Node.js. 

Aqui, você encontrará uma página web com explicações simples, exemplos práticos e um layout interativo para explorar os métodos do console. O projeto explica como usar o console para exibir mensagens, encontrar erros e até medir o tempo de execução de códigos.

A página inclui:
- **Explicações Detalhadas:** Cada método do console é explicado de forma simples, acompanhado de exemplos.
- **Códigos Prontos para Uso:** Você pode copiar os exemplos e testá-los diretamente no seu ambiente Node.js.
- **Interatividade:** A página possui uma barra de pesquisa e botões para copiar os trechos de código com facilidade.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando:
- **HTML:** Para estruturar as páginas e o conteúdo.
